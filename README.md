* **Discord 提醒助手** — 使用 Claude Code 高效協作完成

  [專案連結](https://github.com/JuneChen1/discord-bot)
  <details>
  <summary>💡 核心功能 </summary>
  
  * **智慧排程**：自訂事件與提醒時間（預設事件前一天台灣時間 22:00 通知）。
  * **記憶設定**：可透過 `/remind-default` 儲存個人專屬的預設通知時間。
  * **清單管理**：支援分頁顯示、日期區間查詢（`/reminders-range`）與線上編輯/刪除。
  * **批次匯入**：支援上傳 CSV 檔案一次建立多筆提醒，並具備自動去重機制。
  * **持久防斷**：自動讀取 JSON 資料，Bot 重啟後會自動重新排程並清除過期資料。
